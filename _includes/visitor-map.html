{%- comment -%} Visitor map — a self-hosted stand-in for the ClustrMaps widget that used to live at the bottom of the homepage. ClustrMaps shut down in 2026 without notice, its CDN domain stopped resolving, and no visitor history was carried over, so nothing here depends on that service. How it works, entirely client side: 1. Cloudflare's /cdn-cgi/trace returns the visitor's country code. No key, no account, no personal data beyond the two-letter country. 2. Counts live in Abacus (abacus.jasoncameron.dev), a free keyless counter. One key holds the running total, one key per country holds its tally. 3. Country totals are read back and drawn as dots on the map. Abacus is a hobby service and could go away the same way ClustrMaps did, so every request is wrapped: if any of it fails the map still renders, just without dots or a number. Pass endpoint="https://..." to use the Cloudflare Worker in visitor-counter/ instead. That keeps the data in your own account, returns every country in a single request, and needs no third-party geolocation call. {%- endcomment -%}
